## ⚙️ 2. Visual Quality Control Rules

* **Vector Text Presets:** Use Ideogram specifically for logo typography, as its text-rendering diffusion models preserve clean letterform boundaries.
* **Aspect Ratio Alignment:** Always lock lifestyle background renders to `16:9` ratio to prevent awkward cropping when uploading into Framer, Softr, or Webflow header containers.
* **Color Temperature Matching:** Ensure AI image prompts incorporate morning sun parameters to generate soft, natural ambient lighting that complements `#2E7D32` Forest Green brand elements.
